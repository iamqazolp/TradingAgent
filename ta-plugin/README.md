# ta-plugin — standalone copy

Drop this folder into any project to get Vietnamese stock TA via MCP.

```bash
uv sync
uv run python -m data.ingest --tickers HPG,VNM --days 500
uv run python -m mcp_server.server
```

## Two ways to connect

- **This snapshot** is self-contained (`server_config.json` is not shipped;
  point at this folder's `mcp_server.server`). Re-copy after pulling the main
  checkout — `ta-plugin/` lags `data/`, `indicators/`, `mcp_server/`, `skills/`
  by design.
- **The canonical path** uses the main checkout's `mcp_config.json` (absolute
  `.venv/bin/python` form generated by `scripts/install_skill.py`). Prefer that
  when the parent repo is available.

## MCP config example (for this folder)

```json
{
  "mcpServers": {
    "ta-agent": {
      "type": "stdio",
      "command": "uv",
      "args": ["run", "python", "-m", "mcp_server.server"],
      "cwd": "/path/to/ta-plugin",
      "env": { "TA_AGENT_DB": "var/ta.sqlite" }
    }
  }
}
```
